# P0071 function design

New service module: svc_init clears state; svc_link(up,now) cancels/restarts operation on connection transitions; svc_tick(dt,now) ages/invalidates samples and advances cooldown; svc_due(now,&code) offers a service transaction without owning UART; svc_sent(now) records transmission/retry/cadence and WAIT_REPLY; svc_reply(payload,now,owned) retains raw A3, validates ownership/echo/status and updates or retries; svc_timeout(now) counts failed transaction/retries; svc_bad_frame records failed service-frame validation; svc_read maps diagnostics/raw pairs. Fixed storage only. Private advance/retry/age/pair helpers support these responsibilities. Host tests cover transitions and raw signed encoding.

Changed cn_init/feed/tick/tx_sent/read: initialize services, dispatch valid A3, enforce exclusive connect/normal/service owner and deadlines, fairly schedule telemetry/service, expose new map. New private begin/release/disconnect helpers centralize owner lifecycle and packet building. No new UART/hardware functions. cn_service continues servicing both serial paths while RS485 responds. REGISTER_COUNT68 extends the address map; REGISTER_READ_MAX16 retains the existing response buffer/maximum read size. modbus_reply rejects larger requests with exception2. Main uses the bounded read size. build/image metadata/output names become P0071 brine, tests linked with service.c. Test helpers generate independent replies/serial fixtures, never live device actions. No removed public API.

Operator helper `tools/read_brine.py`: request_block uses only FC04 RPC; capture brackets retained payload reads with sample completion counters, logs UTC timestamps/raw decimal arrays, reconstructs complete CN105 frames explicitly labelled reconstructed and emits provisional signed values only for coherent valid samples. main bounds sample count/interval/output and writes JSONL; no automatic execution or physical changes. Pure decode fixture checked offline; networking only when operator invokes the script.
