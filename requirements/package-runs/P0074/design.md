# P0074 design

Separate board requirements, observed updater contract, protocol rules and chosen application profile. Use hardware-reference, protocol-reference and clean-room-guide folders, a shared evidence legend and a visible known-unknowns ledger. Each substantive section declares provenance; JSON groups carry evidence and confidence. Baseline current P0072 API remains version1.

Golden vectors include valid and invalid frames, pending/completed A3, broadcast/exception cases. A documentation-only checker consumes JSON/Markdown and no firmware/vendor files. Independence review is a desk review and algorithm exercise, not a fresh physical implementation proof. Public docs summarize private hardware evidence without raw logs or network/machine details. No unrelated changes.
