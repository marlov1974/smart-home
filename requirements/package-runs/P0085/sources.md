# P0085 provenance and sources

All ROM/RAM addresses are hexadecimal and refer to the supplied image, candidate **20.01**, not the installed **21.00**. MOT SHA256 `e94f9d9369b5efb9d2af66209fb431fde6ed0a1690b9ce0960adbf5cdb53b0c3`; reconstructed binary SHA256 `d828c2e18a013a6adea8a191448b5c5f7d52ac17b3bbc1182c977e190b60976a`. Toolchain and decoder pins: [P83 provenance](../P0083/provenance.md). No decoder changes in P85. Full exports, vendor inputs and Ghidra projects remain local.

- **S1:** Mitsubishi OCH722A Geodan service manual, printed pp11,63 wiring/test points; pp23–27 and94 menus. Manufacturer-authored local PDF inherited from P83; [source copy](https://ecoinnovation.lv/wp-content/uploads/2023/02/ZEMES_SILTUMSU%CC%84KNIS_GEODAN_SERVISA_INSTRUKCIJA.pdf). Wiring pages were visually verified in P84, reused here. Same supplied Geodan model family; not an MCU schematic.
- **S2:** Renesas M16C/65 hardware manual R01UH0135EJ0210 Rev2.10, local P82 `m16c65.pdf/.txt`, register map and sections14/23, printed pp229,479–483. This identifies peripherals and framing bits; it does not map FTC connectors.
- **S3:** Mitsubishi [FTC board explanation](https://mitsubishi-les.pl/my-360/en/plyta-ftc/ftc-board/), consulted2026-10-11. Separately names CN105 for MELCloud/Procon and CNRF for PAR-WR51R-E. General Ecodan board guidance, not proof of exact installed PCB revision.
- **S4:** Mitsubishi [FTC6 wiring drawing](https://library.mitsubishielectric.co.uk/pdf/download_full/5409), Jan2023. Corroborates WiFi/CN105 and wireless receiver/CNRF on FTC6; does not specify bytes or pin signal levels.
- **S5:** Mitsubishi [QAHV service handbook HWE1517C](https://library.mitsubishielectric.co.uk/pdf/download_full/5499), component illustration p56. Cross-family counterexample only: CNIT handles transmission-power functions there. **Do not transfer its pinout to Geodan.** It demonstrates why connector names are insufficient.
- **S6:** [P81 physical mapping](../P0081/implementation-report.md), [P83 service](../P0083/service-trace.md), [P84 settings](../P0084/settings-trace.md), [P84 transport](../P0084/screen-cn22-trace.md). P81's720 reads concern installed21.00; P83/P84 static results concern candidate20.01.
- **S7:** Operator correction during P85: WiFi probably plugged into the wrong port by the installer. This supersedes the package's “working original MELCloud adapter on CNRF” premise. Location remains reported; actual CNRF/MELCloud communication is not established.

CONFIRMED = documentary fact or exact code/data relation with the stated version. STRONG HYPOTHESIS / INFERRED = supported interpretation, not a proved connector assignment. UNKNOWN = missing evidence; not absence. RESTRICTED = a specific demonstrated gate, not total interface incapability.
