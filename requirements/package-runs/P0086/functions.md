# P0086 function design

New tools/ftc6/p86 modules: energy.py validates BCD/A3 frame/selector, combines bounded samples and reports counter delta quality; uart1.py builds qualified diagnostic frames, validates replies, models effective addresses and decodes logs; settings.py models only evidenced transitions and preserves setting blocks, blocks unqualified apply/rollback; reader.py provides explicit-profile offline dry-run/replay with finite deadlines, no-overwrite output, cancellation and retained raw failure records. Tests and evidence verifier remain in this directory. No shared helpers, native firmware or allowlist changes until Track A establishes need and query safety. Document any additional functions here before editing. No live backend or arbitrary injection.

Implemented paths and contracts are catalogued in docs/functions/ftc6-energy-uart1-qualification.md. Added P86AddressProof.java (single-instruction emulator), verify_local.py (pinned input/operand/root/export validation), run_analysis.py (local headless wrapper), explicit synthetic fixtures and tests. Settings preservation output is an offline diff, not a GET-to-SET translation. Existing native/ARM firmware and diagnostic allowlists remain unchanged.
