P86 authorizes offline work and publication only. Installed firmware, schedules, ownership and native protections remain untouched. The first stage ready for separate authorization is **C0: identification, unpowered continuity and appropriately isolated passive electrical observation**. It includes no injected UART/CN105 packets or port reconfiguration.

1. **C0 — ready as a handoff.** Record exact FTC board/revision, MCU marking, package and orientation. Trace conditional P6_6/P6_7 through components to the connector. A qualified operator verifies reference/isolation, signal amplitude, polarity and bit period with high-impedance instrumentation. Identify the actual source of configuration 08EB bit4 without guessed DIP changes. Record raw scope traces and native communication state. Stop if isolation, levels or routing remain uncertain.
2. **C1 — not yet ready.** Qualify a specific adapter's DTR/RTS behavior, baud/parity, duplex and permitted diagnostic entry/exit. Create a hardware profile only after evidence. Snapshot native state and independently observed communication. Send one open, one small demonstrably non-MMIO RAM read with a justified expected meaning on installed 21.00, then close. The dry-run address 0400 has no known 21.00 expected pattern and is not a selected live test address. Bound each step; no automatic retry. On failure stop transmission, preserve partial bytes and independently verify closure/recovery. Silence is insufficient.
3. **C-log.** After C1, separately authorize log observation/draining. Allow known loss and missing timestamps/checksum. Do not retry after timeout. Correlate a benign CN105 event without labeling D as screen traffic. No full dump without a different validated flash-access path.
4. **A — energy comparison.** Separately authorize sparse heating-counter comparison. A future scoped change must deliberately extend the current firmware allowlist before submission. Read high once and low twice with raw capture; no high retry. Compare integrated GET07, water heat and Shelly energy over matched intervals and against an interval without forced folds. Treat 21.00 compatibility and calibration as unknown. Never call 532/340.
5. **B-read — blocked.** Resolve the internal service1002/CF978 handshake and verified close/recovery first. The proposed test snapshots prior state, reads both complete settings blocks, closes and verifies restoration. Opening C8 changes session state even in a read-first test.
6. **B-write — blocked.** Complete import, persistence and rollback qualification first. Then separately authorize one pump/mode 5→4→5, preserving every neighbor, observing configured level plus independent PWM/flow, and verifying restoration. No live sender is provided.

Keep captures private: wall clock with timezone, host monotonic duration, profile/image identity, raw TX/RX including partial/bad frames, correlation, state before/after and abort reason. Publish no device identity, personal logs or full vendor image. Hardware execution remains disabled in this package.
