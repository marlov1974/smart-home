# P0088 function design

New tools only under tools/ftc6/p88. Implemented: SHA/length/bounds-gated image reader and finite table extraction; descriptor normalization plus reviewed annotations; JSON/CSV/human ledger generation; separate structural/semantic/physical coverage; pure UART6, UART1 snapshot and source-result decoders; manual indexed-bit addressing helper; bounded source-switch Ghidra export; synthetic and private-ROM tests. P83 extraction and P86 regression helpers are reused read-only. No changes to Procon firmware or deployed interfaces. Full semantic coverage and an end-to-end fresh extraction wrapper remain unfinished.

Continuation: add `source_tx.descriptors(image)` to decode the bounded 82A7A..8320C descriptor region into destination-bit/source fields, rejecting malformed headers, overruns and unsupported kinds. Add pure `pack_logical(descriptor, values)` to reproduce field masking/placement and checksum without running callback code or transmitting. Missing values must fail, never silently become zero. Test known target/feedback fixtures, boundaries, crossing-byte fields and missing sources. Extend the source switch exporter with the proven 23-entry outgoing switch. These are package-local additions with no live side effects.

Settings continuation: `settings_peer.advertisement` models the proven service1005 response; `control_response` decodes the bounded state/direction response tables806FE/80718 for1002/1003/1004/end/data-error events. Inputs are explicit internal state, not invented live events. Return raw format/value with no IO. Test state/direction bounds, all table cells, mask boundaries and real decoder operand anchors; this is not a peer scheduler or a complete settings transaction emulator.

Completion continuation: `P88A3Completion.run` verifies the reference binary SHA and project bytes, then follows the bounded CECFA control flow independently of stale function bodies. Output is a private operand listing; no device side effects. `source_tx.call_sites` qualifies contiguous far-pointer pushes and the known packer call; missing descriptor callers fail. `verify_artifacts.verify` cross-checks JSON, CSV, human ledger, coverage counts and source descriptor/field identity, without private firmware or hardware; malformed or stale generated artifacts fail. Tests include missing/noncontiguous call sites and a deliberately corrupted artifact copy.

Settings-transfer continuation: `settings_transfer.ranges(image)` decodes the33 bounded selector ranges; `resolve` applies first-match lookup including selector-zero end marker; `extended_fields` extracts selector, format and direction from the incoming16-bit word; `admitted` reproduces only8BD02's local role/transfer-kind/direction gate. Return structured facts, never wire commands or device writes. Tests cover both directions, all selectors0..1023, endpoint/alias mapping, unmatched selectors and corrupt range tables. The report must distinguish this finite transfer table from all settings reachability.

Persistence continuation: add pure `settings_store.first_dirty_word` and `verify_word` for512-byte desired/shadow images, two16-bit readbacks and explicit failure count. Model the native third-failure shadow update separately from verified persistence. Add `pump_fields` to decode the two proven raw pump bytes; no invented1..5 validation. All functions are local transformations with no IO. Tests cover offsets, word pairing, disagreement, third failure, success and invalid lengths. A named pseudocode module and dependency map will preserve upstream/downstream contracts and unresolved edges.

Bounded exporter continuation: retain the existing two-argument A3 completion default, add an explicit `settings-clock` whitelist entry for94A20..<94A45. Unknown names fail; the same binary/project-byte checks and no-escape CFG traversal apply. This recovers the complete pulse helper despite a stale function body and optimized-away MMIO effects in C.

Pump/timing continuation: add pure `pump_control.selected_level` for the AF400/AF452 branch predicates and `accounting_allowance` for CE2A4's two ROM rows, override, cap and enable gate. These transform explicit raw state only; they neither control hardware nor claim physical watts. Tests cover demand modes, DHW exclusions, profile2 reduction, row boundary21/22, sentinel9999, cap200 and disabled output. Add the984D9 indexed-bit case to the existing architecture regression. No previous package or production implementation changes.

Reduction/energy continuation: add pure `reduction_code` for D3CAC's state/count encoding, `reduction_allowed` for D3E8A's seven signed/unsigned predicates with native16-bit subtraction, and `sample_average` for CD62E's capped sample window with retained previous value when empty. Explicit raw inputs, no IO. Tests cover threshold equality, overflow semantics, each failed predicate, encoded state saturation, and empty/nonempty windows; private ROM assertions pin timers and callback records. D3E44/D3E5E/D3E8A C output is invalid due signed-FB bit operands, so assembly is authoritative.

Re-decompile selected functions only in a separate P88 project after proofs pass; no broad regeneration or EXITD scope expansion.
